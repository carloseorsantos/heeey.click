Uma lousa onde seu agente de IA desenha ao vivo com a sua equipe

O Heeey é um servidor MCP hospedado sobre um canvas Excalidraw multiplayer. Peça ao Claude, ao Cursor ou a qualquer cliente MCP um diagrama de arquitetura e veja ele aparecer num quadro que todos podem abrir, editar e guardar.

Crie sua chave de API grátis Ler o guia de configuração

Entre com um magic link e crie uma chave em Configurações → Integrações.

Terminal 
# Claude Code: um comando, nada para instalar ou rodar localmente
claude mcp add --transport http heeey https://www.heeey.click/api/mcp \
  --header "Authorization: Bearer hk_YOUR_KEY"

Como funciona o servidor MCP do Heeey?

Seu agente chama ferramentas via Streamable HTTP; o Heeey escreve no quadro e transmite cada mudança para quem estiver com ele aberto.

  1. 1

    Conecte uma vez

    Adicione a URL do servidor remoto e sua chave de API a qualquer cliente MCP. Sem processo Node, sem servidor de canvas local.

  2. 2

    Descreva, não posicione

    create_diagram recebe nós e ligações. O Heeey dimensiona as caixas, organiza em camadas e desvia as setas das formas.

  3. 3

    Compartilhe o link

    Todo resultado traz a URL do quadro. A equipe vê as formas surgirem em tempo real e pode continuar editando à mão.

Quais ferramentas o agente recebe?

Treze ferramentas para ler, desenhar e organizar quadros. As leituras devolvem uma cena compacta (rótulos, conexões, coordenadas arredondadas) para economizar contexto.

create_diagram · layout_board
Fluxogramas, arquiteturas, organogramas e mapas mentais com layout automático, ou arrume um quadro bagunçado.
add_elements · delete_elements
Desenhe formas, texto e setas conectadas a partir de especificações curtas com ids estáveis, e atualize depois.
get_board · list_boards · search_boards
Leia o que há num quadro, ou encontre um por qualquer texto escrito no canvas.
create_board · rename_board · trash_board
Gerencie quadros; os que forem para a lixeira podem ser restaurados pelo app.
list_folders · create_folder · move_board
Mantenha os diagramas feitos pelo agente organizados junto com os seus.
E uma API REST
A mesma chave funciona com /api/v1 para scripts e CI.

Perguntas frequentes

O servidor MCP do Heeey é grátis?

Sim. Crie uma conta com seu e-mail, gere uma chave de API e conecte seu agente sem custo.

Com quais clientes MCP ele funciona?

Qualquer cliente que aceite servidores MCP remotos via Streamable HTTP com um cabeçalho personalizado, incluindo Claude Code e Cursor. O guia de configuração tem configurações prontas para copiar e colar.

Qual a diferença para um servidor MCP de Excalidraw local?

Servidores locais desenham num canvas que vive na sua máquina. O Heeey é hospedado: os quadros ficam salvos na sua conta, têm uma URL compartilhável e várias pessoas (e agentes) podem trabalhar no mesmo quadro ao mesmo tempo.

Posso controlar o que o agente pode fazer?

Sim. As chaves de API têm escopo de leitura ou de leitura e escrita, e podem ser revogadas a qualquer momento. Veja autenticação e permissões.

As pessoas precisam de conta para ver o diagrama?

Não. Qualquer pessoa com o link do quadro pode abri-lo, no modo "pode editar" ou "apenas leitura".
