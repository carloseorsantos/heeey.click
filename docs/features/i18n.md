# Internacionalização (i18n)

O **Heeey** foi construído com arquitetura de internacionalização nativa e fortemente tipada, oferecendo suporte completo a múltiplos idiomas tanto na interface da aplicação quanto no editor gráfico Excalidraw.

---

## 🌍 Idiomas Suportados

| Idioma | Código (`Locale`) | Código Excalidraw (`excalidrawLangCode`) | Status |
|---|---|---|---|
| **Português (Brasil)** | `pt-BR` | `pt-BR` | Idioma primário e de referência |
| **English (US)** | `en` | `en` | Totalmente traduzido e verificado |

---

## 🧠 Arquitetura do Sistema (`src/i18n/`)

A solução de i18n do Heeey foi desenvolvida sob medida para ser extremamente leve, reativa e sem dependências pesadas externas:

```
src/i18n/
├── index.tsx          # Provider React, hook useI18n, detector e formatador ICU
└── locales/
    ├── pt-BR.ts       # Dicionário de mensagens em Português (tipagem base)
    └── en.ts          # Dicionário de mensagens em Inglês
```

### 1. Tipagem Estrita em Tempo de Compilação
- O TypeScript extrai recursivamente todas as chaves aninhadas do dicionário `ptBR` gerando o tipo union `MessageKey` (ex.: `'dashboard.newBoard'`, `'header.saving'`, `'errors.unauthorized'`).
- Se qualquer componente tentar utilizar uma chave inexistente ou com erro de digitação, a compilação falha imediatamente.
- O arquivo `en.ts` implementa a interface `Messages`, garantindo que nenhuma tradução fique faltando em inglês.

### 2. Suporte a Plurais no Padrão ICU
Mensagens dinâmicas suportam regras de pluralização complexas através do formatador `formatMessage`, que utiliza a API nativa `Intl.PluralRules`:

```typescript
// Exemplo em pt-BR.ts:
elementCount: '{count, plural, one {# elemento} other {# elementos}}',
collaboratorsOnline: '{count, plural, one {# pessoa conectada} other {# pessoas conectadas}}',
```

### 3. Interpolação de Parâmetros
Substituição simples de variáveis envoltas por chaves:
```typescript
t('common.welcomeUser', { name: 'Carlos' });
// "Bem-vindo, Carlos!" ou "Welcome, Carlos!"
```

## 🔄 Detecção e Persistência de Preferência

O Heeey seleciona o idioma do usuário de forma inteligente em três etapas:

1. **Preferência Salva (`localStorage`)**:
   - Se o usuário já selecionou um idioma anteriormente no seletor de idiomas, a chave `heeey_locale` é lida do navegador.
2. **Detecção do Navegador (`navigator.languages`)**:
   - Se for o primeiro acesso, o sistema inspeciona a lista ordenada de idiomas preferidos do navegador.
   - Navegadores com preferência por `pt*` recebem `pt-BR`; navegadores com preferência por `en*` recebem `en`.
3. **Fallback Padrão**:
   - Para qualquer outro idioma não mapeado, o padrão do sistema é `pt-BR`.

---

## 🎨 Sincronização com o Canvas do Excalidraw

O motor gráfico Excalidraw possui suas próprias traduções internas (ferramentas, diálogos de exportação, paleta de cores e atalhos).

O Heeey sincroniza o idioma selecionado diretamente na propriedade `langCode` do componente Excalidraw através da variável `excalidrawLangCode`:
- Quando o usuário altera o idioma no Heeey, os botões, menus contextuais e caixas de diálogo do canvas mudam de idioma instantaneamente, mantendo a experiência perfeitamente uniforme.

---

## 📅 Formatação de Datas e Números

Todas as datas exibidas nos cartões de quadros e no histórico de versões adaptam-se dinamicamente ao idioma ativo:
- Em `pt-BR`: `"editado há 5 minutos"`, `"23 de setembro de 2026"`.
- Em `en`: `"edited 5 minutes ago"`, `"September 23, 2026"`.

## 🛠️ Como Adicionar um Novo Idioma

Para estender o suporte a um novo idioma (por exemplo, Espanhol `es`):

1. Crie o arquivo `src/i18n/locales/es.ts` implementando a interface `Messages`.
2. Adicione a entrada correspondente no array `LOCALES` em `src/i18n/index.tsx`:
   ```typescript
   export const LOCALES = [
     { id: 'pt-BR', label: 'Português', excalidrawLangCode: 'pt-BR' },
     { id: 'en', label: 'English', excalidrawLangCode: 'en' },
     { id: 'es', label: 'Español', excalidrawLangCode: 'es-ES' },
   ];
   ```
3. Registre o dicionário no mapa `DICTIONARIES`.
4. Os testes automatizados em `src/__tests__/i18n.test.ts` validarão automaticamente a integridade das mensagens!
