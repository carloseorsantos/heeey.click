¿Cómo funciona el servidor MCP de Heeey?

Tu agente llama a herramientas mediante Streamable HTTP; Heeey escribe en la pizarra y difunde cada cambio a quien la tenga abierta.

  1. 1

    Conéctalo una vez

    Añade la URL del servidor remoto y tu clave de API a cualquier cliente MCP. Sin proceso de Node ni servidor de lienzo local.

  2. 2

    Describe, no coloques

    create_diagram recibe nodos y conexiones. Heeey ajusta el tamaño de las cajas, las ordena por capas y traza las flechas alrededor de las formas.

  3. 3

    Comparte el enlace

    Cada resultado incluye la URL de la pizarra. Tu equipo ve aparecer las formas en tiempo real y puede seguir editando a mano.

¿Qué herramientas recibe el agente?

Trece herramientas para leer, dibujar y organizar pizarras. Las lecturas devuelven una escena compacta (etiquetas, conexiones, coordenadas redondeadas) para ahorrar contexto.

create_diagram · layout_board
Diagramas de flujo, arquitecturas, organigramas y mapas mentales con disposición automática, u ordena una pizarra desordenada.
add_elements · delete_elements
Dibuja formas, texto y flechas conectadas a partir de especificaciones breves con ids estables, y actualízalas después.
get_board · list_boards · search_boards
Lee lo que hay en una pizarra o encuentra una por cualquier texto escrito en su lienzo.
create_board · rename_board · trash_board
Gestiona pizarras; las que se envían a la papelera se pueden restaurar desde la app.
list_folders · create_folder · move_board
Mantén los diagramas del agente organizados junto a los tuyos.
Y una API REST
La misma clave funciona con /api/v1 para scripts y CI.

Preguntas frecuentes

¿El servidor MCP de Heeey es gratis?

Sí. Crea una cuenta con tu correo, genera una clave de API y conecta tu agente sin coste.

¿Con qué clientes MCP funciona?

Cualquier cliente que admita servidores MCP remotos mediante Streamable HTTP con una cabecera personalizada, incluidos Claude Code y Cursor. La guía de configuración tiene configuraciones listas para copiar y pegar.

¿En qué se diferencia de un servidor MCP de Excalidraw local?

Los servidores locales dibujan en un lienzo que vive en tu equipo. Heeey está alojado: las pizarras se guardan en tu cuenta, tienen una URL para compartir y varias personas (y agentes) pueden trabajar en la misma a la vez.

¿Puedo controlar lo que puede hacer el agente?

Sí. Las claves de API tienen alcance de lectura o de lectura y escritura, y se pueden revocar en cualquier momento. Consulta autenticación y permisos.

¿Hace falta una cuenta para ver el diagrama?

No. Cualquiera con el enlace de la pizarra puede abrirla, en modo «puede editar» o «solo lectura».
